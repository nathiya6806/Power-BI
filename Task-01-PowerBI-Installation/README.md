
# Student Performance Analysis – Power BI & Python

## Project Overview

This project focuses on exploring and analyzing student academic performance using Python. The objective is to understand student grades, study habits, attendance, and other factors through data analysis and visualization.

## Dataset

- **Source:** [UCI Machine Learning Repository – Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student+performance)
- **File:** `student-mat.csv`
- **Domain:** Education
- **Target variable:** G3 (Final Grade)

## Technologies Used

- Python
- Google Colab
- Pandas – Data manipulation
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Power BI Desktop – Business intelligence and reporting

## Work Completed

1. Imported and explored the student performance dataset.
2. Checked missing values and duplicate records.
3. Generated descriptive statistical summaries.
4. Calculated average, highest, and lowest final grades.
5. Analyzed study time and academic performance.
6. Created visualizations using Matplotlib and Seaborn.
7. Interpreted the results and documented key findings.

## Visualizations

- Student Final Grade Distribution
- Study Time vs Average Final Grade

## Key Findings

The analysis explores:
- Overall student academic performance.
- Relationship between study time and final grades.
- Gender-wise average performance.
- Attendance and academic performance.
- Past failures and final grades.

The findings are based on statistical analysis and show associations rather than proving causation.
